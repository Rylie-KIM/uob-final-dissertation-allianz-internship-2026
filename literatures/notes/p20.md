## 🇰🇷 한국어 요약

### 1. 문제 정의 — 탐색-활용 딜레마의 형식화

**K-arm bandit 문제:**

- $K$개의 머신(arm)이 있으며, 머신 $i$를 플레이하면 독립적이고 동일한 분포를 따르는 보상 $X_{i,1}, X_{i,2}, \ldots$를 생성한다. 기대 보상은 $\mu_i$ (알 수 없음).
- $\mu^* = \max_{1 \leq i \leq K} \mu_i$ = 최적 머신의 기대 보상
- $\Delta_i = \mu^* - \mu_i$ = 머신 $i$의 gap (최적 대비 열등함)

**정책 $A$의 후회(Regret):** $n$번의 플레이 후 기대 후회는

$$\text{Regret}_n = \mu^* n - \sum_{j=1}^{K} \mu_j \cdot \mathbb{E}[T_j(n)] = \sum_{j : \mu_j < \mu^*} \Delta_j \cdot \mathbb{E}[T_j(n)]$$

여기서 $T_j(n)$은 머신 $j$가 처음 $n$번 플레이 중 선택된 횟수.

**Lai & Robbins (1985) 하한 (점근적):**

$$\mathbb{E}[T_j(n)] \geq \left(\frac{1}{D(p_j \| p^*)} + o(1)\right) \ln n$$

여기서 $D(p_j \| p^*)$는 KL divergence. 이 하한은 **최선의 정책도 로그 후회를 피할 수 없음**을 보여준다. Auer et al.의 기여는 이것을 **유한 시간(finite-time)**에 균등하게 달성하는 것이다.

### 2. UCB1 알고리즘 — "불확실성 앞의 낙관주의"

#### 2-1. 알고리즘 (Figure 1)

```
결정론적 정책: UCB1
초기화: 각 머신을 한 번씩 플레이
루프:
  - 인덱스가 최대인 머신 j를 플레이:
      UCB_j(t) = x̄_j + √(2 ln t / n_j)
    여기서 x̄_j = 머신 j의 현재 평균 보상
           n_j = 머신 j가 지금까지 플레이된 횟수
           t = 전체 플레이 횟수
```

**UCB 인덱스:**

$$\text{UCB}_j(t) = \bar{x}_j + \sqrt{\frac{2 \ln t}{n_j}}$$

- **첫 번째 항 $\bar{x}_j$:** 현재 추정된 평균 보상 (활용, exploitation)
- **두 번째 항 $\sqrt{2\ln t / n_j}$:** 불확실성 보너스 (탐색, exploration). $n_j$가 작을수록(덜 플레이된 머신), 보너스가 커진다. 시간이 지남에 따라 $\ln t$가 천천히 증가하므로 탐색을 계속 유도한다.

이것이 **"불확실성 앞의 낙관주의(Optimism in the Face of Uncertainty)"** 원칙: 덜 알려진 머신을 그것의 *잠재적 최선* 성능으로 평가한다.

#### 2-2. Theorem 1 — UCB1의 후회 상한 (유한 시간)

**Theorem 1** (Auer et al., 2002):

$K > 1$이고, 보상 분포의 지지가 $[0,1]$에 포함될 때, UCB1 정책의 임의의 플레이 횟수 $n$ 후 기대 후회는 최대:

$$\mathbb{E}[\text{Regret}_n] \leq \left[8 \sum_{i : \mu_i < \mu^*} \frac{\ln n}{\Delta_i}\right] + \left(1 + \frac{\pi^2}{3}\right)\left(\sum_{j=1}^{K} \Delta_j\right)$$

**해석:**
- 첫 번째 항: 각 열등한 머신의 gap $\Delta_i$에 반비례하는 로그 후회 (gap이 크면 빨리 구분 가능하므로 후회 작음)
- 두 번째 항: 유한 상수 — 점근적으로 무시 가능
- **전체 후회는 $O(\log n)$** — 탐색이 로그 속도로 줄어들어 장기적으로 최적에 수렴

이를 위해 사용된 핵심 도구는 **Chernoff-Hoeffding 경계 (Fact 1):**

$$\mathbb{P}\{S_n \geq n\mu + a\} \leq e^{-2a^2/n} \quad \text{and} \quad \mathbb{P}\{S_n \leq n\mu - a\} \leq e^{-2a^2/n}$$

증명의 핵심 단계: $T_i(n) \leq \lceil 8\ln n / \Delta_i^2 \rceil + 1 + \pi^2/3$ (기대값으로).

#### 2-3. UCB2 (Theorem 2) — 개선된 상수

UCB2 정책은 Epoch 기반으로 플레이 횟수를 지수적으로 늘리는 전략:

$$a_{n,r} = \sqrt{\frac{(1+\alpha)\ln(en/\tau(r))}{2\tau(r)}}, \quad \tau(r) = \lceil (1+\alpha)^r \rceil$$

**Theorem 2:** UCB2의 기대 후회는 최대:

$$\sum_{i:\mu_i < \mu^*} \left(\frac{(1+\alpha)(1+4\alpha)\ln(2e\Delta_i^2 n)}{2\Delta_i} + \frac{c_\alpha}{\Delta_i}\right)$$

$\alpha \to 0$으로 선택하면 leading constant를 $1/(2\Delta_i^2)$에 임의로 가깝게 만들 수 있다. 이는 Lai-Robbins 하한의 $1/D(p_j \| p^*)$에 근접하는 최적에 가까운 상수다.

#### 2-4. $\varepsilon_n$-GREEDY (Theorem 3)

$\varepsilon_n = \min\{1, cK/(d^2 n)\}$으로 설정:

- 확률 $1 - \varepsilon_n$으로 현재 최선의 머신 선택
- 확률 $\varepsilon_n$으로 무작위 머신 선택

**Theorem 3:** 적절한 파라미터 설정 하에서, $\varepsilon_n$-GREEDY는 열등한 머신 $j$를 선택할 확률이 $O(c/(d^2 n))$으로 감소. **전체 후회는 $O(\log n)$** 달성.

그러나 UCB1과 달리, $\varepsilon_n$-GREEDY는 gap 하한 $d$를 사전에 알아야 하는 단점이 있다. UCB1은 **완전히 파라미터-free**.

### 3. UCB1 vs. Thompson Sampling 비교

이 논문(P20)과 P21(Thompson Sampling Tutorial)을 함께 읽어야 Build 05의 전체 그림이 나온다.

| 항목 | UCB1 (P20) | Thompson Sampling (P21) |
|------|-----------|------------------------|
| **철학** | 빈도주의 — 사전 분포 불필요 | 베이지안 — 사전 분포 필요 |
| **탐색 메커니즘** | 결정론적 신뢰 상한 보너스 | 확률적 사후 분포 샘플링 |

| **사전 지식 요구** | 보상 분포 지지 $[0,1]$만 알면 됨 | 사전 분포 명세 필요 — 오명세 시 성능 저하 |

**핵심:** UCB1이 P20이 제공하는 이론적 기준선. Build 05에서 Thompson Sampling이 UCB1보다 더 빠르게 미조사 세그먼트를 발견함을 시뮬레이션으로 보여야 한다.

### 4. Allianz SFP 연구에서의 직접 적용

#### 4-1. 보험 청구 탐색 문제로의 매핑

| Bandit 개념 | Allianz 보험 탐색 해석 |
|------------|----------------------|
| **Arm $k$** | 청구 세그먼트 (예: `claim_type × postcode_risk` 조합) |
| **보상 $X_{k,t}$** | 세그먼트 $k$의 $t$번째 조사에서의 사기 발견 여부 ($\in \{0, 1\}$) |
| **기대 보상 $\mu_k$** | 세그먼트 $k$의 실제 사기율 (알 수 없음) |
| **플레이 횟수 $n_k$** | 세그먼트 $k$에서 지금까지 수행된 조사 횟수 |
| **$\bar{x}_k$** | 세그먼트 $k$에서 현재까지 발견된 사기 비율 |
| **UCB 보너스** | 조사 횟수가 적은 세그먼트에 대한 탐색 인센티브 |
| **$\Delta_k$** | 세그먼트 $k$의 실제 사기율과 최고 사기율 세그먼트 간의 gap |

**UCB1 정책 (보험 탐색 버전):**

$$\text{UCB}_k(t) = \hat{\mu}_k + \sqrt{\frac{2\ln t}{n_k}}$$

여기서 $\hat{\mu}_k = \frac{\text{사기 발견 건수}_k}{n_k}$ = 세그먼트 $k$의 경험적 사기율.

**SFP 루프 문제와의 연결:**

SFP 루프에서 순수 탐욕 정책(greedy)은 높은 $\hat{\mu}_k$인 세그먼트만 계속 조사한다. Theorem 3에서 보이듯 이는 선형 후회($\sim n$)로 이어진다 — 미조사 세그먼트의 진짜 사기율을 영원히 학습하지 못한다. UCB1의 $\sqrt{2\ln t / n_k}$ 보너스가 이를 교정한다.

#### 4-3. 코드 구현 (`randomisation_policy.py`)

```python
import numpy as np

class UCB1Policy:
    """
    Auer, Cesa-Bianchi & Fischer (2002) UCB1 policy.
    보험 청구 세그먼트 탐색을 위한 이론적 기준선.
    Theorem 1: E[Regret_n] <= 8 * sum(ln(n)/Delta_i) + (1 + pi^2/3) * sum(Delta_i)
    """
    def __init__(self, n_segments: int):
        self.K = n_segments
        self.counts = np.zeros(n_segments)   # n_k: 각 세그먼트 조사 횟수
        self.rewards = np.zeros(n_segments)  # sum of fraud indicators
        self.t = 0                            # 전체 플레이 횟수

    def select_segment(self) -> int:
        self.t += 1
        # 초기화: 각 세그먼트를 한 번씩 플레이
        if self.t <= self.K:
            return self.t - 1

        x_bar = self.rewards / (self.counts + 1e-9)          # 경험적 사기율
        bonus = np.sqrt(2 * np.log(self.t) / (self.counts + 1e-9))  # UCB 보너스
        ucb_index = x_bar + bonus
        return int(np.argmax(ucb_index))

    def update(self, segment: int, reward: float):
        self.counts[segment] += 1
        self.rewards[segment] += reward

class EpsGreedyPolicy:
    """
    Auer et al. Theorem 3: epsilon_n = min(1, cK / (d^2 * n)) 정책.
    UCB1보다 약함: gap d를 사전에 알아야 함.
    """
    def __init__(self, n_segments: int, c: float = 1.0, d: float = 0.1):
        self.K = n_segments
        self.c = c
        self.d = d
        self.counts = np.zeros(n_segments)
        self.rewards = np.zeros(n_segments)
        self.t = 0

    def select_segment(self) -> int:
        self.t += 1
        eps = min(1.0, self.c * self.K / (self.d**2 * self.t))
        if np.random.random() < eps:
            return np.random.randint(self.K)  # 무작위 탐색
        return int(np.argmax(self.rewards / (self.counts + 1e-9)))  # 활용

    def update(self, segment: int, reward: float):
        self.counts[segment] += 1
        self.rewards[segment] += reward
```

### 5. 한계 (논문이 명시)

- **보상이 $[0,1]$ 지지를 가질 때만 Theorem 1, 2, 3 성립.** Theorem 4 (UCB1-NORMAL)가 정규 분포로의 확장을 다루지만, 미지의 분산이 있을 때 더 복잡한 인덱스 필요.
- **Gap $\Delta_i$가 비슷할 때 후회가 커짐:** $\Delta_i$가 모든 arm에 대해 작으면 $8\ln n / \Delta_i$ 항이 크다 — 세그먼트 간 진짜 사기율이 비슷한 보험 환경에서 불리.
- **비정상(nonstationary) 환경 미지원:** 보험 사기 패턴은 시간에 따라 변하지만, UCB1은 고정된 $\mu_k$를 가정한다. Thompson Sampling의 비정상 TS(P21 §6.3)가 이를 해결.
- **컨텍스트 미활용:** UCB1은 각 청구 건의 개별 특성(금액, 차종, 과거 청구 이력)을 활용하지 않는다. LinUCB 등의 컨텍스트 확장이 필요하며, P21의 컨텍스트 벤딧 섹션이 이를 제공.
- **파라미터-free이지만 로그 상수 큼:** UCB1의 leading constant $8/\Delta_i^2$는 Lai-Robbins 이론적 최적인 $1/D(p_j\|p^*)$보다 최대 4배 크다. UCB2는 이를 개선하지만 파라미터 $\alpha$ 필요.

## 🇬🇧 English Summary

### 1. Problem — The Multi-Armed Bandit Formulation

A $K$-armed bandit is defined by independent reward random variables $X_{i,n}$ for each machine $i \in \{1,\ldots,K\}$ with unknown expectations $\mu_i$. The **regret** of an allocation policy $A$ after $n$ plays is:

$$\text{Regret}_n = \mu^* n - \sum_{j=1}^{K} \mu_j \mathbb{E}[T_j(n)] = \sum_{j:\mu_j < \mu^*} \Delta_j \mathbb{E}[T_j(n)]$$

The **Lai and Robbins (1985) lower bound** establishes that for any policy, the expected number of times a suboptimal arm $j$ is played satisfies:

$$\mathbb{E}[T_j(n)] \geq \left(\frac{1}{D(p_j \| p^*)} + o(1)\right) \ln n$$

This means no policy can achieve sub-logarithmic regret asymptotically. Auer et al.'s contribution is to achieve this logarithmic regret **uniformly over finite time** with simple, computationally efficient policies, and for any reward distribution with bounded support — not just specific parametric families.

### 2. UCB1 Algorithm — Formal Statement

**UCB1 index:**

$$\text{UCB}_j(t) = \bar{x}_j + \sqrt{\frac{2 \ln t}{n_j}}$$

**Theorem 1** (the central result): For all $K > 1$, if UCB1 is run on $K$ machines having arbitrary reward distributions with support in $[0, 1]$, its expected regret after any number $n$ of plays is at most:

$$\left[8 \sum_{i:\mu_i < \mu^*} \frac{\ln n}{\Delta_i}\right] + \left(1 + \frac{\pi^2}{3}\right)\left(\sum_{j=1}^{K} \Delta_j\right)$$

**Proof sketch:** For each suboptimal arm $i$, bound $\mathbb{E}[T_i(n)]$. Whenever arm $i$ is selected at time $t$, at least one of three events must hold:

1. $\bar{X}^*_s \leq \mu^* - c_{t,s}$ (optimal arm's estimate is pessimistic)
2. $\bar{X}_{i,s_i} \geq \mu_i + c_{t,s_i}$ (arm $i$'s estimate is optimistic)
3. $\mu^* < \mu_i + 2c_{t,s_i}$ (the confidence interval is too wide, i.e., arm $i$ hasn't been played enough)

Using Chernoff-Hoeffding bounds, events 1 and 2 each have probability $\leq t^{-4}$. Event 3 is false when $s_i \geq \lceil 8\ln n / \Delta_i^2 \rceil$. Therefore $\mathbb{E}[T_i(n)] \leq \lceil 8\ln n / \Delta_i^2 \rceil + 1 + \pi^2/3$.

### 3. Additional Policies

**UCB2 (Theorem 2):** Epoch-based policy with exponentially growing plays per epoch. With parameter $0 < \alpha < 1$, the leading constant approaches $1/(2\Delta_i^2)$ — closer to the Lai-Robbins optimal $1/D(p_j \| p^*)$ — at the cost of introducing $\alpha$.

**$\varepsilon_n$-GREEDY (Theorem 3):** Sets $\varepsilon_n = \min\{1, cK/(d^2 n)\}$ where $d$ is a lower bound on all gaps. Achieves $O(\log n)$ regret but requires prior knowledge of $d$. UCB1 is strictly superior in this regard — fully parameter-free.

**UCB1-NORMAL (Theorem 4):** Extension to normally distributed rewards with unknown variance. Uses sample variance as an estimate:

$$\bar{x}_j + \sqrt{16 \cdot \frac{q_j - n_j \bar{x}_j^2}{n_j - 1} \cdot \frac{\ln(n-1)}{n_j}}$$

### 4. Direct Relevance to Allianz SFP Research

#### 4-1. Arm-to-Segment Mapping

| Bandit Concept | Allianz Insurance Interpretation |
|---------------|----------------------------------|
| Arm $k$ | Claim segment (e.g. cross of `claim_type` and `postcode_risk`) |
| Reward $X_{k,t}$ | Fraud indicator for $t$-th investigation in segment $k$ |
| $\mu_k$ | True (unknown) fraud rate in segment $k$ |
| $n_k$ | Historical investigation count for segment $k$ |
| UCB bonus $\sqrt{2\ln t / n_k}$ | Exploration incentive inversely proportional to investigation intensity |
| Gap $\Delta_k$ | Difference between segment $k$'s fraud rate and the highest-fraud-rate segment |

**The SFP connection:** A purely greedy policy (always investigate the model's top-scored claims) concentrates investigations on already well-understood segments. As Theorem 3 shows, this leads to linear regret — fraud in under-investigated segments is never discovered. The UCB1 bonus corrects this by forcing periodic investigation of low-$n_k$ segments.

#### 4-2. UCB1 vs. Thompson Sampling in Build 05

Both policies are implemented in `randomisation_policy.py`. UCB1 serves as the frequentist baseline that Thompson Sampling must outperform:

- **When UCB1 is preferred:** When no prior knowledge about fraud rates is available, or when a regulator requires a transparent, deterministic policy with provable guarantees.
- **When Thompson Sampling is preferred:** When historical fraud rate estimates by segment are available (informing Beta priors), when claim features can be leveraged for contextual personalisation, and when empirical speed of convergence matters more than worst-case guarantees.

| **Build 02 (SFP Detector)** | Step 4 (Segment Blind Spots): segments with $n_k \ll$ average are exactly those with highest UCB bonus — natural prioritisation. |
| **Build 01 (SFP Simulation)** | Theoretical justification that greedy investigation (no UCB bonus) incurs linear regret — i.e., the SFP loop worsens indefinitely without exploration. |
| **Build 03 (Unbiased Eval)** | UCB1-driven investigation produces a more uniform coverage of segments, reducing extreme propensity scores and improving IPS estimate stability. |

### 5. Limitations

- **Stationary rewards assumption:** Real fraud patterns are nonstationary (tactics evolve seasonally, post-COVID changes in motor claims frequency). UCB1 assumes fixed $\mu_k$; Thompson Sampling's nonstationary extension (P21 §6.3) is more suitable.
- **No contextual information:** UCB1 treats each segment as a homogeneous arm. Individual claim features (`amount`, `prior_claims`, `product_line`) are ignored. Contextual bandits (LinUCB, or Thompson Sampling with logistic regression) are required for individual-level exploration.
- **Large gap-dependent constants:** When all $\Delta_i$ are small (similar true fraud rates across segments), UCB1's $8\ln n / \Delta_i$ term becomes very large. Thompson Sampling empirically performs better in this regime.
- **Requires $[0,1]$ bounded support:** Fraud is binary (0/1), so this is satisfied. But if the reward were continuous (e.g., claim amount recovered), UCB1-NORMAL or a non-parametric approach would be needed.
- **No cost-benefit:** UCB1 treats all arms symmetrically. Allianz's investigation budget is not uniform across segments — some investigations are expensive (complex commercial claims), some cheap (simple windscreen claims). A cost-aware extension is needed for Build 05's cost-benefit analysis.

## 🎯 Interview Talking Points (P20-specific)

| Prompt | Use P20 to say… |
|--------|----------------|
| *"Why do you need a bandit algorithm for fraud investigation?"* | "The fundamental problem is exploration versus exploitation. A purely greedy policy — always sending investigators to the model's top-scored claims — concentrates resources on already well-investigated segments. Auer et al. (2002) prove this leads to linear regret: you never learn about fraud in under-investigated segments. The UCB1 algorithm's bonus term √(2 ln t / n_k) ensures every segment gets investigated often enough to maintain an accurate fraud rate estimate." |
| *"What is the UCB1 regret guarantee and why does it matter?"* | "Theorem 1 guarantees expected regret at most 8 Σ (ln n / Δ_i) plus a finite constant. The O(log n) growth means that in the long run, almost all investigations go to the truly high-fraud segments. The constant 8/Δ_i² is somewhat conservative — UCB2 can get it to 1/(2Δ_i²), approaching the Lai-Robbins theoretical optimum." |
| *"How does UCB1 differ from Thompson Sampling for this problem?"* | "Both achieve O(log T) regret asymptotically, but differ fundamentally in philosophy. UCB1 is frequentist — no prior distribution needed, just historical counts. Thompson Sampling is Bayesian — it requires a Beta prior over each segment's fraud rate, but this prior can be informed by historical claims data, which Allianz has. In practice, Thompson Sampling converges faster in the early phases when few investigations have been done per segment — exactly the situation when breaking out of an SFP loop." |
| *"Why is ε-greedy insufficient compared to UCB1?"* | "Auer et al.'s Theorem 3 shows ε_n-greedy can achieve O(log n) regret if ε_n decays at rate 1/n. But it requires knowing a lower bound d on the gap between the best and second-best segments. UCB1 requires no such prior knowledge — it is truly parameter-free, adapting the exploration rate automatically through the log bonus. In a live insurance system where fraud rates change, not having to tune d is a significant operational advantage." |
| *"What is the practical limitation of UCB1 for insurance?"* | "Two main ones: first, it ignores individual claim features — it treats all claims in a segment identically, when in fact amount, prior_claims, and claim_type within a segment carry information. Second, it assumes stationary fraud rates, but insurance fraud patterns are seasonal and evolve with economic cycles. These limitations motivate Thompson Sampling (P21), which naturally extends to contextual bandits and nonstationary variants." |
| *"How do you use UCB1 in your Build 05 implementation?"* | "I implement UCBPolicy as the baseline in randomisation_policy.py. For each investigation round, the policy selects the segment with highest UCB index: empirical fraud rate plus √(2 ln t / n_k). I then run simulations comparing UCB1 regret against pure greedy (which incurs linear regret, illustrating the SFP loop) and Thompson Sampling (which typically outperforms UCB1 in early rounds). The cost-benefit extension adds an investigation cost term, making the UCB index cost-weighted." |
| *"What is the relevance of the Lai-Robbins lower bound here?"* | "It establishes that no policy can avoid O(log T) regret — so UCB1's guarantee is order-optimal. This means there's no fundamentally better exploration strategy; Thompson Sampling's practical advantage is in the constant, not the order. In the Allianz context, this tells us that some degree of 'wasted' investigation of low-fraud segments is mathematically unavoidable — the question is just how small we can make that waste." |
| *"How does UCB1 help break the SFP loop?"* | "The SFP loop is driven by a greedy policy: only investigate where the model scores high, only get labels where you investigate. UCB1 breaks this by guaranteeing that every segment $k$ is investigated $Θ(\ln n / \Delta_k^2)$ times — proportional to how hard it is to distinguish $k$ from the best segment. Segments the model has historically ignored get large bonuses until their fraud rates are accurately estimated. This directly addresses Build 02's Step 4 (Segment Blind Spot Analysis)." |
