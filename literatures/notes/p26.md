## 🇰🇷 한국어 요약

### 1. 문제 정의 — 밴딧 문제와 SFP 루프 연결

밴딧 문제(Bandit Problem)의 핵심: **행동(arm 선택)을 통해 수집된 정보만으로 최적 행동을 학습해야 하며, 이때 탐색(exploration)과 활용(exploitation) 사이의 트레이드오프를 관리**해야 한다.

SFP 루프와의 직접 연결: Allianz 사기 탐지 모델은 사실상 밴딧 문제의 특수 경우다:

- **Arm:** 각 청구건에 대한 "조사 여부" 결정 (또는 모델 버전 v1/v2/v3의 임계값)
- **Reward:** 조사 후 "사기 발견 여부" (Y=1)
- **Feedback:** 조사된 청구건에서만 reward를 관찰 (선택적 피드백)
- **문제:** 기존 정책(모델 점수 기반 조사)이 항상 같은 arm만 선택 → 탐색 없음 → 나머지 arm의 reward 분포 미학습 → SFP 루프

**핵심 통찰:** 밴딧 알고리즘의 탐색 메커니즘(UCB, Thompson Sampling)이 SFP 루프를 구조적으로 방지한다. 탐색이 강제적으로 "모델이 낮게 본" 청구건을 조사하게 하여, 이 영역의 라벨을 수집하고 다음 모델의 훈련 데이터 편향을 줄인다.

### 2. 핵심 기술 개념 및 수식

#### 2-1. 확률적 밴딧 환경 (Chapter 4, Core Definitions)

**정의 4.1 (확률적 밴딧):** 분포들의 집합 $\nu = (P_a : a \in \mathcal{A})$로 이루어진 환경. 여기서 $\mathcal{A}$는 arm 집합.

각 라운드 $t$에서:
1. 정책 $\pi$가 arm $A_t \in \mathcal{A}$를 선택
2. 환경이 $P_{A_t}$에서 reward $X_t$를 독립적으로 샘플링
3. 정책이 $(A_t, X_t)$를 관찰

**평균 보상:** $\mu_a(\nu) = \mathbb{E}[X : X \sim P_a]$

**최적 평균:** $\mu^*(\nu) = \max_{a \in \mathcal{A}} \mu_a(\nu)$

**최적 arm:** $a^*(\nu) = \arg\max_{a \in \mathcal{A}} \mu_a(\nu)$

#### 2-2. 후회(Regret) — 학습 목표 (Chapter 4, Section 4.4)

**정의 (Equation 4.1):** n 라운드에 걸쳐 정책 $\pi$의 환경 $\nu$에 대한 후회:

$$R_n(\pi, \nu) = n\mu^*(\nu) - \mathbb{E}\left[\sum_{t=1}^n X_t\right]$$

이는 최적 arm을 n번 선택했을 때의 기대 누적 보상과 실제 정책의 기대 누적 보상의 차이.

**Allianz 번역:**
- Arm = 청구건 세그먼트 (혹은 각 청구건)
- Reward = 조사 1건당 사기 발견 (사기=1, 비사기=0)
- Regret = 최적 조사 정책(모든 실제 사기 청구를 조사) 대비 현재 정책의 기대 손실

**Bayesian 후회 (Equation 4.4):**

$$BR_n(\pi, Q) = \int_{\mathcal{E}} R_n(\pi, \nu) \, dQ(\nu)$$

여기서 $Q$는 환경 $\nu$에 대한 사전 분포. Thompson Sampling은 Bayesian 후회를 최소화하는 동기로 개발됨.

#### 2-3. 후회 분해 보조정리 (Lemma 4.5 — Regret Decomposition)

**핵심 결과:** 후회는 각 하위최적 arm이 선택된 횟수로 분해됨:

$$R_n = \sum_{a \in \mathcal{A}} \Delta_a \cdot \mathbb{E}[T_a(n)]$$

여기서:
- $\Delta_a(\nu) = \mu^*(\nu) - \mu_a(\nu)$: arm $a$의 **하위최적 격차(suboptimality gap)**
- $T_a(n) = \sum_{t=1}^n \mathbb{I}[A_t = a]$: n 라운드에서 arm $a$가 선택된 횟수

**SFP 관련 해석:**
- $\Delta_a$ = 세그먼트 $a$ (예: 특정 우편번호 범주)에서 실제 사기 발견 가능성과 최적 조사 정책의 차이
- SFP 루프 = $\mathbb{E}[T_a(n)] \approx 0$ for 저점수 세그먼트 (탐색 없음)
- 밴딧 해결책: $\mathbb{E}[T_a(n)]$을 최소화하는 동시에 $\Delta_a$가 큰 arm을 충분히 탐색

#### 2-4. UCB (Upper Confidence Bound) 알고리즘 (Chapter 7)

UCB1 알고리즘:

$$A_t = \arg\max_{a \in \mathcal{A}} \left[ \hat{\mu}_a(t-1) + \sqrt{\frac{2\ln t}{T_a(t-1)}} \right]$$

여기서 $\hat{\mu}_a(t-1)$은 arm $a$의 경험적 평균 보상, $\sqrt{\frac{2\ln t}{T_a(t-1)}}$은 불확실성 보너스(exploration bonus).

**UCB 후회 상한 (Chapter 7):**

$$R_n \leq \sum_{a: \Delta_a > 0} \left[ \frac{8\ln n}{\Delta_a} + \left(1 + \frac{\pi^2}{3}\right)\Delta_a \right]$$

이는 $O(\sqrt{n \ln n})$ 후회 상한을 의미 — 사실상 최적.

**Allianz 적용:**

```
각 청구 세그먼트 a (postcode_risk × claim_type 조합)에 대해:

  μ_hat_a = 해당 세그먼트 과거 조사에서 사기 발견율
  T_a     = 해당 세그먼트 조사 횟수
  
UCB 점수 = μ_hat_a + √(2 ln(총 조사 수) / T_a)

→ 조사 횟수가 적은 세그먼트: 불확실성 보너스 크다 → 탐색 유도
→ 높은 사기 발견율 세그먼트: 경험적 평균 크다 → 활용
```

#### 2-5. Thompson Sampling (Chapter 36, Section 36.1-36.2)

베이지안 밴딧 알고리즘:

**알고리즘:**
1. 각 arm $a$에 대해 prior $Q_a$로 시작 (Bernoulli reward → Beta prior)
2. 라운드 $t$에서:
   - 각 arm에서 $\theta_a^{(t)} \sim Q_a^{(t-1)}$ 샘플링
   - $A_t = \arg\max_a \theta_a^{(t)}$ 선택
   - Reward $X_t$ 관찰, posterior $Q_{A_t}^{(t)} \propto Q_{A_t}^{(t-1)} \cdot \mathcal{L}(X_t \mid \theta_{A_t})$ 업데이트

Bernoulli 밴딧에서: $Q_a^{(t)} = \text{Beta}(\alpha_a + S_a(t),\ \beta_a + F_a(t))$

여기서 $S_a(t)$는 arm $a$의 성공 횟수, $F_a(t)$는 실패 횟수.

**Thompson Sampling의 후회 상한 (Chapter 36):**

$$\mathbb{E}[R_n] \leq (1+\epsilon) \sum_{a: \Delta_a > 0} \frac{\ln n}{\Delta_a} \cdot \text{KL}^{-1}(\mu_a, \mu^*) + O\left(\frac{1}{\epsilon^2}\right)$$

이는 Lai-Robbins 하한과 일치하는 점근적 최적성.

**Bayesian 후회 최소화 (Chapter 36.1):** Thompson Sampling은 $BR_n(\pi, Q)$를 최소화. 이는 Allianz 사전 지식(도메인 전문가의 세그먼트별 사기 기저율 추정)을 prior로 인코딩할 수 있음을 의미.

#### 2-6. 선형(Contextual) 밴딧 (Chapter 36.3 — Thompson Sampling for Linear Bandits, Chapters 18-19)

**핵심 아이디어:** 각 arm/청구건이 특성 벡터 $x_t \in \mathbb{R}^d$를 가지며, 보상 평균이 선형 함수:

$$\mu(x_t, a_t) = \langle x_t, \theta^* \rangle$$

여기서 $\theta^* \in \mathbb{R}^d$는 미지의 파라미터 벡터.

**실용적 의미 (Chapters 18-19):** 청구건별 특성(청구 금액, 우편번호 위험 점수, 사전 청구 횟수, 제품 유형)을 특성 벡터로 사용하면, 선형 밴딧이 세그먼트별 독립 UCB보다 더 효율적으로 탐색. 특성 유사도가 정보를 전이.

**Thompson Sampling for Linear Bandits (Section 36.3):** Bayesian 선형 회귀와 결합:

$$\theta^{(t)} \sim \mathcal{N}(\hat{\theta}_{t-1}, V_{t-1}^{-1})$$
$$A_t = \arg\max_{a} \langle x_a, \theta^{(t)} \rangle$$

여기서 $V_t = \lambda I + \sum_{s=1}^t x_{A_s} x_{A_s}^\top$, $\hat{\theta}_t = V_t^{-1} \sum_{s=1}^t X_s x_{A_s}$.

이 알고리즘의 후회는 $\tilde{O}(\sqrt{dnT})$ — 특성 차원 $d$, 탐색 라운드 $T$에 대해.

#### 2-7. ε-greedy (단순 베이스라인)

$$A_t = \begin{cases} \text{random arm} & \text{with probability } \varepsilon \\ \arg\max_a \hat{\mu}_a & \text{with probability } 1-\varepsilon \end{cases}$$

가장 단순한 탐색-활용 균형. UCB/Thompson Sampling보다 후회 상한이 큼 ($O(n)$ vs $O(\sqrt{n})$). 하지만 구현이 간단하고 해석 가능. Build 05의 베이스라인.

### 3. 실험 결과 — 보장된 수렴 특성

책의 핵심 이론적 결과:

| 알고리즘 | 후회 상한 | Allianz 활용 |
|---------|----------|-------------|
| ε-greedy | $O(n)$ (또는 $O(n^{2/3})$ 최적 ε 사용 시) | 베이스라인, 해석 용이 |
| UCB1 | $O(\sqrt{n \ln n})$ | 세그먼트별 독립 적용 가능 |
| Thompson Sampling | 점근 최적 (Lai-Robbins 하한 일치) | 베이지안 prior 활용, 도메인 지식 인코딩 |
| Linear TS (Ch. 36.3) | $\tilde{O}(\sqrt{dnT})$ | 청구건 특성 활용 가능 |

**핵심 정리 (Lai-Robbins 하한):** 어떤 일관적(consistent) 정책도 다음보다 더 나은 후회를 달성할 수 없음:

$$\liminf_{n \to \infty} \frac{R_n}{\ln n} \geq \sum_{a: \Delta_a > 0} \frac{\Delta_a}{\text{KL}(P_a \| P_{a^*})}$$

이는 $\ln n$ 속도의 후회가 정보 이론적 하한임을 의미. UCB와 Thompson Sampling은 이 하한에 매칭.

### 4. Allianz SFP 연구와의 직접 연관성

#### 4-1. 빌드 단계별 기여

| Allianz 연구 단계 | P26의 기여 |
|-----------------|-----------|
| **Build 00: Data Exploration** | 각 청구 세그먼트 $a$의 과거 조사율 $T_a/n$과 사기 발견율 $\hat{\mu}_a$를 EDA에서 계산. 어떤 세그먼트가 탐색 부족한지(낮은 $T_a$, 높은 불확실성) 파악. |
| **Build 01: SFP Simulation** | SFP 루프를 "탐색 없는 순수 활용 정책" (ε=0)으로 모델화. 후회 분해 보조정리를 사용하여 탐색 없을 때의 누적 후회 시뮬레이션. |
| **Build 02: Loop Detection** | SFP 신호로 낮은 $T_a$ 세그먼트 = 탐색 부족 신호. Lemma 4.5의 $\Delta_a \cdot \mathbb{E}[T_a(n)]$ 관점에서 루프 심각도 정량화. |
| **Build 03: Unbiased Evaluation** | 탐색으로 수집된 라벨은 IPS 가중치를 통해 처리. 탐색 정책의 propensity score = ε (ε-greedy) 또는 Thompson 사후 분포 → Build 03 IPS 추정기의 정확한 분모. |
| **Build 04: Intervention Analysis** | 밴딧 정책을 개입으로 설정한 DiD 분석. 개입 전(순수 활용) vs 후(ε-greedy 또는 UCB)의 세그먼트별 사기 발견율 변화를 DiD로 추정. |
| **Build 05: Randomisation Strategy** | **P26이 Build 05의 핵심 이론 기반.** ε-greedy (베이스라인) → UCB (세그먼트별) → Thompson Sampling (prior 활용) → Linear TS (특성 활용) 순서로 알고리즘 구현. Cost-benefit 분석: 탐색 비용 = 조사 자원, benefit = 미래 루프 감소. |
| **Build 06: Causal Mitigation** | 밴딧 탐색으로 수집된 라벨을 IPW 재가중치에 활용. 탐색 정책하에서 수집된 데이터는 selection bias가 알려져 있음 (propensity = 탐색 확률) → DoWhy 모델에 정확한 propensity 제공. |

#### 4-2. SFP 루프와 밴딧 후회의 관계

```
SFP 루프 = 탐색 없는 밴딧 정책의 장기 결과:

현재 정책 (순수 활용):
  T_a(n) = n for a = 고위험 세그먼트  [항상 선택]
  T_a(n) ≈ 0 for a = 저위험 세그먼트  [선택 안 됨]

결과:
  저위험 세그먼트의 진정한 μ_a를 알 수 없음 → SFP 루프
  Lemma 4.5: R_n = Σ_a Δ_a E[T_a(n)] → 저위험 Δ_a 모름 → 후회 과소추정

밴딧 해결:
  ε-greedy: 매 조사의 ε 비율을 무작위 세그먼트에 할당
  UCB: 불확실성(낮은 T_a) 높은 세그먼트에 조사 집중
  TS: 사전 지식 + 관찰 데이터로 posterior 업데이트, 사기 의심 세그먼트 탐색

결과:
  탐색 → 저위험 세그먼트의 실제 μ_a 추정
  → SFP 루프 중단
  → Build 03 IPS 추정기가 편향 없이 작동
  → v4 모델 훈련 데이터가 대표성 있음 (Article 10.4)
```

### 5. 코드/아키텍처 함의

`test/builds/05_randomisation_strategy/randomisation_policy.py` 핵심 구현:

```python
import numpy as np
from scipy.stats import beta

class BanditPolicy:
    """
    P26 기반: Allianz 사기 조사 밴딧 정책
    각 claim_segment를 arm으로, 사기 발견을 reward로 처리
    """
    
    def __init__(self, segments: List[str], epsilon: float = 0.1):
        self.segments = segments
        self.epsilon = epsilon
        # Prior: Beta(1, 1) = uniform (P26 Chapter 36)
        self.alpha = {s: 1.0 for s in segments}  # 성공 횟수 + 1
        self.beta_params = {s: 1.0 for s in segments}  # 실패 횟수 + 1
        self.counts = {s: 0 for s in segments}
        self.total = 0
    
    def ucb_select(self) -> str:
        """P26 Chapter 7: UCB1 알고리즘"""
        ucb_scores = {}
        for s in self.segments:
            if self.counts[s] == 0:
                return s  # 한 번도 선택 안 된 arm 우선
            mu_hat = self.alpha[s] / (self.alpha[s] + self.beta_params[s])
            exploration = np.sqrt(2 * np.log(self.total) / self.counts[s])
            ucb_scores[s] = mu_hat + exploration
        return max(ucb_scores, key=ucb_scores.get)
    
    def thompson_select(self) -> str:
        """P26 Chapter 36: Thompson Sampling (Bernoulli/Beta)"""
        # Equation 4.4: Bayesian regret minimisation
        samples = {s: beta.rvs(self.alpha[s], self.beta_params[s]) 
                   for s in self.segments}
        return max(samples, key=samples.get)
    
    def epsilon_greedy_select(self) -> str:
        """P26 baseline: ε-greedy"""
        if np.random.random() < self.epsilon:
            return np.random.choice(self.segments)  # 탐색
        else:
            mu_hats = {s: self.alpha[s]/(self.alpha[s]+self.beta_params[s]) 
                       for s in self.segments}
            return max(mu_hats, key=mu_hats.get)  # 활용
    
    def update(self, segment: str, fraud_found: int):
        """Posterior 업데이트 (P26 Chapter 36 Beta-Bernoulli)"""
        if fraud_found:
            self.alpha[segment] += 1
        else:
            self.beta_params[segment] += 1
        self.counts[segment] += 1
        self.total += 1
    
    def compute_regret_decomposition(self) -> dict:
        """P26 Lemma 4.5: Regret Decomposition"""
        mu_hat_best = max(
            self.alpha[s]/(self.alpha[s]+self.beta_params[s]) 
            for s in self.segments
        )
        regret_by_segment = {}
        for s in self.segments:
            mu_hat_s = self.alpha[s]/(self.alpha[s]+self.beta_params[s])
            delta_s = mu_hat_best - mu_hat_s
            regret_by_segment[s] = delta_s * self.counts[s]
        return {
            'total_regret': sum(regret_by_segment.values()),
            'by_segment': regret_by_segment
        }
```

### 6. 한계 (책이 명시 및 Allianz 맥락)

- **독립적 보상 가정:** 표준 밴딧은 라운드 간 독립 보상을 가정. 보험 사기는 동일 청구인의 반복 청구, 조직화된 사기 링 등 상관 구조 존재 → 독립성 가정 위배
- **고정 arm 집합 가정:** 청구 세그먼트가 시간이 지나면서 변화 (신제품, 우편번호 재분류 등) → 비정상적(non-stationary) 밴딧으로 확장 필요
- **탐색 비용 명시적 모델링 필요:** 밴딧 이론의 "cost = opportunity cost only"가 보험에서는 부족. 조사에는 명시적 비용(조사관 시간, 법적 비용)이 있음. Cost-benefit 분석(Build 05)이 이를 반영해야 함
- **컨텍스추얼 밴딧의 feature 선택:** Linear TS (Ch. 36.3)의 성능은 특성 벡터 $x_t$의 품질에 의존. 어떤 청구 특성이 사기 발견 가능성에 선형적으로 관련되는지 검증 필요
- **책 Chapter 36의 주의:** 사용자 지시에서 "Chapter 36 (linear contextual bandits)"로 명시되어 있으나, 실제 책에서 Chapter 36은 "Thompson Sampling"이며, Section 36.3이 "Linear Bandits with Thompson Sampling"을 다룸. 컨텍스추얼/선형 밴딧의 광범위한 처리는 Chapters 18-19에 있음.

## 🇬🇧 English Summary

### 1. Problem — Bandits as the Mathematical Foundation for SFP Loop Breaking

The bandit problem: an agent must learn to take optimal actions from feedback that is only available for chosen actions, managing the explore-exploit trade-off. This is precisely the structure of Allianz's fraud investigation problem:

- **Arms:** claim segments (postcode_risk × claim_type combinations, or individual claims)
- **Reward:** fraud discovered = 1, no fraud = 0
- **Feedback:** reward observed only for investigated claims (selected arms)
- **SFP loop = pure exploitation with ε = 0:** the model always investigates high-score claims, never exploring low-score segments. The reward distribution in low-score segments is unknown — so the next model is trained on biased data.

Bandit algorithms (UCB, Thompson Sampling) structurally break the SFP loop by forcing exploration of under-investigated segments, collecting labels there, and reducing the selection bias in the next training cycle.

### 2. Core Technical Concepts and Formulae

#### 2-1. Stochastic Bandit Environment (Chapter 4)

**Definition 4.1:** A stochastic bandit environment is a collection of distributions $\nu = (P_a : a \in \mathcal{A})$.

At each round $t$: policy $\pi$ selects arm $A_t$; environment samples reward $X_t \sim P_{A_t}$; policy observes $(A_t, X_t)$.

**Optimal mean:** $\mu^*(\nu) = \max_{a \in \mathcal{A}} \mu_a(\nu)$

**Suboptimality gap:** $\Delta_a(\nu) = \mu^*(\nu) - \mu_a(\nu)$

#### 2-2. Regret — The Learning Objective (Section 4.4)

**Definition (Equation 4.1):**

$$R_n(\pi, \nu) = n\mu^*(\nu) - \mathbb{E}\left[\sum_{t=1}^n X_t\right]$$

The expected shortfall from always selecting the best arm.

**Bayesian regret (Equation 4.4):**

$$BR_n(\pi, Q) = \int_{\mathcal{E}} R_n(\pi, \nu) \, dQ(\nu)$$

where $Q$ is a prior over environments. Thompson Sampling minimises Bayesian regret.

#### 2-3. Regret Decomposition Lemma (Lemma 4.5)

$$R_n = \sum_{a \in \mathcal{A}} \Delta_a \cdot \mathbb{E}[T_a(n)]$$

where $T_a(n) = \sum_{t=1}^n \mathbb{I}[A_t = a]$ is the number of times arm $a$ is pulled.

**SFP interpretation:**
- In pure exploitation, $\mathbb{E}[T_a(n)] \approx 0$ for low-scoring segments → their $\Delta_a$ is unknown
- The SFP loop's cost is not captured in the observed regret because these arms are never pulled
- Bandit exploration forces $\mathbb{E}[T_a(n)] > 0$ for all arms, making $\Delta_a$ estimable everywhere

#### 2-4. UCB Algorithm (Chapter 7)

$$A_t = \arg\max_{a \in \mathcal{A}} \left[ \hat{\mu}_a(t-1) + \sqrt{\frac{2\ln t}{T_a(t-1)}} \right]$$

The exploration bonus $\sqrt{2\ln t / T_a(t-1)}$ automatically allocates more investigation to segments with fewer past investigations, regardless of their estimated fraud rate.

**Regret bound:** $R_n \leq \sum_{a: \Delta_a > 0} \left[\frac{8\ln n}{\Delta_a} + (1+\pi^2/3)\Delta_a \right] = O(\sqrt{n \ln n})$

#### 2-5. Thompson Sampling (Chapter 36)

**Algorithm:** At each round, sample $\theta_a^{(t)} \sim Q_a^{(t-1)}$ (posterior for arm $a$), then select $A_t = \arg\max_a \theta_a^{(t)}$.

For Bernoulli rewards (fraud/no fraud): Beta-Bernoulli conjugate model.
- Prior: $\text{Beta}(\alpha_a, \beta_a)$
- Posterior update: $\alpha_a \leftarrow \alpha_a + \mathbb{I}[\text{fraud}]$, $\beta_a \leftarrow \beta_a + \mathbb{I}[\text{no fraud}]$

**Key advantage over UCB:** Domain expert knowledge (prior belief about segment-level fraud rates) can be encoded in the prior $(\alpha_a, \beta_a)$. This is directly applicable in Allianz where claims handlers have intuitions about segment fraud rates.

**Asymptotic optimality:** Thompson Sampling matches the Lai-Robbins lower bound on expected regret.

#### 2-6. Linear Bandits and Contextual Thompson Sampling (Chapter 36.3, Chapters 18-19)

When claim features $x_t \in \mathbb{R}^d$ are available, the linear bandit model assumes:

$$\mu(x_t) = \langle x_t, \theta^* \rangle$$

**Thompson Sampling for Linear Bandits (Section 36.3):**

$$\theta^{(t)} \sim \mathcal{N}(\hat{\theta}_{t-1}, V_{t-1}^{-1}), \quad V_t = \lambda I + \sum_{s \leq t} x_{A_s} x_{A_s}^\top$$

**Regret bound:** $\tilde{O}(\sqrt{dnT})$ — scales as square root of both feature dimension and horizon.

**Advantage for Allianz:** Feature similarity transfers information across claim segments. A claim in a new postcode with features similar to known high-fraud segments gets appropriate uncertainty bounds even without direct investigation history there.

**Note on book structure:** The user instructions reference "Chapter 36 (linear contextual bandits)." The book's Chapter 36 is titled "Thompson Sampling," with Section 36.3 specifically covering "Linear Bandits" under Thompson Sampling. Broader contextual bandit material appears in Chapters 18 (Contextual Bandits) and 19 (Stochastic Linear Bandits).

### 3. Experimental Guarantees

The book's key theoretical results:

| Algorithm | Regret Bound | Allianz Use Case |
|-----------|-------------|-----------------|
| ε-greedy | $O(n)$ or $O(n^{2/3})$ with optimal ε | Baseline, interpretable, easy to audit |
| UCB1 | $O(\sqrt{n \ln n})$ | Segment-level independent application |
| Thompson Sampling | Asymptotically optimal (matches Lai-Robbins) | Bayesian prior encodes domain knowledge |
| Linear TS (Ch. 36.3) | $\tilde{O}(\sqrt{dnT})$ | Transfers information across similar claim segments |

**Lai-Robbins lower bound:** No consistent policy can achieve better than:

$$\liminf_{n \to \infty} \frac{R_n}{\ln n} \geq \sum_{a: \Delta_a > 0} \frac{\Delta_a}{\text{KL}(P_a \| P_{a^*})}$$

UCB and Thompson Sampling match this bound asymptotically — they are informationally optimal.

#### 4-2. The Explore-Exploit Framing of SFP Mitigation

The SFP loop is a pure exploitation failure. The solution — exploration — has a principled theoretical treatment in bandit algorithms:

The current Allianz system: sets ε = 0 implicitly. Investigation policy = sort by model score, investigate top k. Low-scoring claims receive zero exploration. Lemma 4.5 guarantees this produces growing regret over time as high-$\Delta_a$ low-scoring segments go unexplored.

The bandit solution: introduces structured exploration that is:
- Informationally efficient (UCB/TS achieve near-optimal regret)
- Auditable (exploration decisions are transparent and algorithmically determined)
- Compliant (Article 14 human oversight: humans set ε and can override)
- Convergent (as $T_a(n) \to \infty$ for all $a$, the SFP loop vanishes)

### 5. Limitations

- **Independent reward assumption:** Standard bandits assume round-by-round independent rewards. Insurance fraud involves correlated patterns (repeat claimants, organised fraud rings) — the independence assumption is violated. Extension to correlated bandits needed.
- **Stationary arm assumption:** Claim segment compositions change over time (new products, postcode reclassification) → non-stationary bandit extensions (sliding window UCB, discounted TS) required for long-term deployment.
- **Explicit investigation costs:** Bandit theory treats cost only as opportunity cost. Insurance investigations have explicit costs (investigator time, legal costs). Build 05's cost-benefit analysis must augment the bandit framework with explicit cost models.
- **Contextual feature quality:** Linear TS performance depends on the quality of the feature vector $x_t$. Claims features must be verified to relate linearly to fraud probability — log transformations of `amount`, interaction terms for `product_line × claim_type` may be needed.
