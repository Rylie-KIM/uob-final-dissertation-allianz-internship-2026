# Paper Comparison Table — AMTLP SFP Loop

**Defined Problem: AMTLP**
A motor insurance total loss prediction service's Self-Fulfilling Prophecy (SFP) Loop problem, where the model's own scrapping decisions force labels on future training data, causing each retrained model version to amplify the previous version's over-confident predictions.

**AMTLP:** Allianz Motor Total Loss Prediction

**Paper Categories** (a paper may belong to multiple):
1. **Define** — Explains what the SFP Loop problem is and why it occurs at a mathematical or structural level. Helps the Claims Operations team understand why the refreshed model's performance degrades over successive retraining cycles.
2. **Detect** — Provides a method or observable signal for detecting the SFP Loop in a deployed service. To be implemented as code (Build 02).
3. **Mitigate** — Proposes a concrete method for reducing or breaking the SFP Loop. To be implemented as code (Builds 05–06).
